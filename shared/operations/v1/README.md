# Feature operations V1

`features.json` is the machine-readable Task 2 operations matrix.

Every implemented feature must state how the owner can inspect, diagnose, configure, repair/reset, authorize, audit, and verify it. A control may be `not_applicable` only with a written reason explaining why the current implemented feature has no relevant state or action. Future plans belong in the spec tasks, not as deferred controls inside a completed feature row.

The owner-control self-check validates this file and checks every future registered command references a listed feature.
