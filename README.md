# Retold

The classic Pokémon games, rebuilt as a real iPhone app. Not an emulator: Retold's own engine
reads the maps, pictures, words and music from your own cartridge file and plays the game
natively, with more options than the original ever had.

Planned: Red, Blue, Yellow, Gold, Silver, Crystal, FireRed, LeafGreen, Ruby, Sapphire and
Emerald. Only the official US English cartridges are accepted.

Retold ships no game data. You need your own legally obtained cartridge file.

Thanks to the [pret](https://github.com/pret) community, whose disassemblies document how the
original games work.
